# POS System - نظام نقاط البيع

## Quick Start / البدء السريع

### Prerequisites / المتطلبات
- XAMPP (PHP 8.1+, MySQL, Apache)
- Git (for updates)

### Installation / التثبيت

1. **Extract** the ZIP file to `C:\xampp\htdocs\POS`
   
   فك الضغط إلى `C:\xampp\htdocs\POS`

2. **Start XAMPP** and run Apache & MySQL
   
   شغّل XAMPP ثم Apache و MySQL

3. **Create database** named `pos_database` in phpMyAdmin
   
   أنشئ قاعدة بيانات `pos_database` في phpMyAdmin

4. **Run installer**: Right-click `install.bat` → Run as Administrator
   
   شغّل `install.bat` كمسؤول

5. **Access**: http://localhost:8000
   
   افتح: http://localhost:8000

### Default Login / بيانات الدخول
- **Email**: admin@example.com
- **Password**: password

⚠️ **Change the password immediately after first login!**

تغيير كلمة المرور فوراً بعد أول تسجيل دخول!

### Update / التحديث
- From system: Settings → System Updates → Check for Updates
- Manual: Double-click `update.bat`

### Support / الدعم
Check `logs` folder for error logs.
راجع مجلد `logs` للسجلات.
